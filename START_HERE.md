## 🔧 Setup in 3 Steps

### Step 1: Install
```bash
npm install
```

### Step 2: Configure API Key
Edit `.env.local`:
```env
GEMINI_API_KEY=your_api_key_here
```

### Step 3: Run
```bash
npm run dev
```

Visit: http://localhost:5173/

## 🆘 Need Help?

### Quick Fixes

**Build fails?**
```bash
rm -rf node_modules package-lock.json
npm install
npm run build
```

**Environment issues?**
```bash
# Make sure .env.local exists with:
GEMINI_API_KEY=your_key_here
```

**Want to verify?**
```bash
./verify-build.sh
```
